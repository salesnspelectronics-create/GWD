# V40 — Online Dependency Flow Fix

## Authoritative dependency modes

- Added standardized modes: `Online`, `Offline Only`, and `Hybrid`.
- Legacy saved values `Online / Normal` and `Local First` are migrated in memory to `Online` and `Hybrid`.
- The selected mode now persists across page rebuilds, source-folder changes, Start Over, and application restarts.
- Changing the source no longer silently forces `Offline Only`.

## Online

- Skips offline repository preparation and offline readiness validation.
- The Dependencies page allows immediate continuation.
- Frontend repair uses standard `npm install` without `--offline` or `--prefer-offline`.
- Backend restore uses configured online NuGet sources without the offline-only NuGet configuration.
- Logs explicitly report `Mode: Online`, `Offline Repository: Skipped`, and `NPM Source: Internet`.

## Offline Only

- Keeps mandatory repository readiness for manual wizard navigation.
- The real build also performs authoritative offline validation before compilation when fingerprints do not prove a previous successful validation.
- Frontend restore uses the centralized `npm install --offline` command policy.
- Offline npm/NuGet failures clearly state that Internet fallback is disabled.

## Hybrid

- The Dependencies page allows immediate continuation and reports that the offline repository is optional.
- NuGet resolution uses local repository/system cache before nuget.org.
- npm uses `--prefer-offline` with Internet registry fallback.
- A failed fallback produces a Hybrid-specific error explaining that local caches and online registry resolution were exhausted.

## Guard and UI corrections

- npm install arguments are generated by one centralized mode switch.
- The only generated `--offline` install command belongs to `Offline Only`.
- Public offline readiness validation rejects Online/Hybrid mode instead of silently running an offline test.
- Online mode disables Prepare Offline Repository and Test Offline Readiness actions.
- Hybrid keeps offline preparation optional; Offline Readiness testing is reserved for Offline Only.

## Preserved V39 behavior

- Fast Local Test default, incremental/change-aware builds, Fast IIS Update, Full IIS Deploy, Offline Repository, Deployment History/stage timing, Diagnostic Bundle, Remote Validation, cancellation, Auto Deploy, health check, rollback, and stale-UI verification remain present.

## Version

- Product, assembly, and file version: `40.0.0`.
