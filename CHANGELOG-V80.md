# V80 — Application-owned UI version contract

Requires a frontend-build-generated `wwwroot/gwd-ui-version.json` containing `{"version":"<release>"}` and checks it against the source release version before deployment. After activation, independently fetches `/gwd-ui-version.json` over HTTP and compares it against the release manifest; mismatch or missing contract fails closed. This must be generated by NSPOffice build from the exact version React displays; GWD does not generate this file.

**Integration requirement:** NSPOffice frontend build must emit `gwd-ui-version.json` into its built static output from the same version source used by the UI. Until this is configured, source-based deployments will be intentionally blocked. This cannot by itself prove the React UI renders the value without an application-side contract.

No .NET build, IIS deployment, production DB changes or migrations performed.
