# Generic Web Deployment Manager V14.9

- Added application identity fields on the first page: Application name, IIS site name, Database name.
- Default identity is NSP Office Automation / NSPOfficeAutomation.
- Database and IIS identity are shown later without forcing duplicate entry.
- Deployment Location path field enlarged; Browse is aligned beside it.
- Log levels now re-render the existing on-screen log, so Minimal/Normal/Verbose visibly differ.
- Log level is locked while deployment is running.
- Live elapsed timer resets at Deploy and updates during the operation.
- Current operation gets a dedicated full-width one-line area above log/browser actions.
- Bottom navigation buttons enlarged.
